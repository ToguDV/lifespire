# ADR-011: React 19 + Vite web stack

- **Status:** Accepted
- **Date:** 2026-10-18
- **Related:** [`ARCHITECTURE.md` §5.1](../../ARCHITECTURE.md), `packages/design-tokens`, ADR-006, ADR-016

## Context

The web app is the main platform and the M0 target. It needs fast local development, a small static build that Cloudflare Pages can host, an interactive SVG map, and a clear split between server state (which retries and syncing) and local UI state. It also has to stay tolerable on a mid-range Android browser.

## Decision

`apps/web` is **React 19 + TypeScript + Vite**. **TanStack Router** owns routing and **TanStack Query** owns server state (cache, retry, offline mutations), while **Zustand** holds local and run-session UI state. Styling is **Tailwind CSS + shadcn/ui** consuming `packages/design-tokens`. The map is **SVG generated by `engine.layoutMap()`** with **Framer Motion** animations. The app ships as an installable **PWA** via `vite-plugin-pwa`.

## Consequences

- + One stack for routing, cache and UI state, each with a single obvious owner.
- + `design-tokens` is the single source of color, typography and spacing for web (and partially for mobile).
- + A static build with no server runtime, cheap to host and cached for offline use.
- − Three state libraries in one app require discipline about which store owns what.
- − The SVG map must be profiled to keep animations at 60 fps on low-end devices.
